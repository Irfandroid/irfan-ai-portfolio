# Portfolio Redesign Specification

## Direction

Rebuild the portfolio as a **Cobalt Archive**: a warm editorial publication inspired by cobalt-and-white tile narratives, archive sheets, and calibration marks. The pattern is structural, not wallpaper: it frames evidence, separates narrative panels, and gives the site a recognisable visual signature.

## Why this direction

The previous dark AI Systems Lab made every section feel like one dense dashboard. This replacement restores breathing room and human warmth while keeping technical credibility. The page should feel like an artifact someone wants to read, not a product UI someone has to operate.

## Audience and success

- Recruiters can identify AI Engineering direction, strongest evidence, and contact path in 30 seconds.
- Engineers can follow a project from problem to architecture, decision, failure, and repository.
- Qalbu leads the experience as a mini technical presentation, not a normal project card.
- Copy is specific and Indonesian-first; claims remain grounded in existing public sources.

## Visual dials

- Overhaul: 9/10
- Variance: 8/10
- Density: 4/10
- Motion: 4/10

## System

- Canvas: warm ivory, cobalt, charcoal, and one muted terracotta signal.
- Typography: Sora for readable body and interface text, Bodoni Moda for selected human-centered emphasis, JetBrains Mono for factual metadata.
- Composition: asymmetrical publication spreads, thin rules, narrative panels, and a real calibration pattern.
- Motion: one restrained page reveal plus image crop and underline transitions; transform and opacity only.

## Kept product truth

Existing routes, anchors, public GitHub and LinkedIn links, real profile photo, MDX project evidence, static export, and browser-local CV upload/download remain in scope. No metrics, awards, responsibilities, or outcomes are invented.

## Pattern rules

The cobalt pattern is used only where it carries meaning: profile calibration, project architecture, and section transitions. It uses crisp authored SVG geometry; no gradient, glow, fake screenshot, or decorative blob.

## Out of scope

No backend, CMS, authentication, analytics, database, contact form, or new dependency. Figma context is not available in this workspace, so the Figma skill contributes inspection and accessibility guardrails rather than imported design assets.
